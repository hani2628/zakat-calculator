# zakat-calculator
# Features:
Calculates zakat based on user input of savings, gold, silver, and other eligible assets.
Provides an easy-to-understand result, showing the zakat amount owed.
# Technologies:
HTML
CSS
JavaScript
# How to Use:
Clone or download the repository.
Open the index.html file in a web browser.
Enter your assets in the input fields.
Click "Calculate" to view the zakat amount due.
